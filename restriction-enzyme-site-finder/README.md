# Restriction Enzyme Site Finder

A beginner bioinformatics project written in Python.

## Features

- Detects restriction enzyme recognition sites
- Reports enzyme names
- Displays recognition sequences
- Shows all matching positions in DNA

## Supported Enzymes

- EcoRI
- BamHI
- HindIII
- NotI
- XhoI
- PstI
- SmaI
- KpnI

## Future Improvements

- Read FASTA files
- Export results to CSV
- GUI using Tkinter
- Visualization of enzyme cut sites
- Support 100+ enzymes using Biopython
