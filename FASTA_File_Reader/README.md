# FASTA File Reader and Sequence Analyzer

## Overview

This project reads DNA sequences stored in FASTA format and performs a simple sequence analysis.

## Features

- Read FASTA files
- Extract sequence names
- Calculate sequence length
- Count nucleotides (A, T, G, C)
- Calculate GC Content

## Input Format

Example:

```
>Human_Hemoglobin
ATGGTGCACCTGACTCCTGAGGAGAAGTCT
```

## Output

```
Sequence Name : Human_Hemoglobin
Sequence Length : 31
A : 6
T : 7
G : 10
C : 8
GC Content : 58.06%
```
## Concepts Used

- File Handling
- Dictionaries
- Functions
- Loops
- String Operations
