# DNA To Protein Translator

## Description

This project translates a DNA sequence into its corresponding protein sequence using the standard genetic code.

---

## Features

- Accepts DNA sequence from user
- Converts DNA to uppercase
- Reads codons (3 bases at a time)
- Uses the standard genetic code
- Stops translation at the first Stop Codon
- Displays the translated protein

## Concepts Used

- Dictionary
- Functions
- Loops
- String slicing
- Conditional statements
