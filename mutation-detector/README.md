# Mutation Detector

A simple Python program to compare two DNA sequences and identify mutations.

## Features

- Compare two DNA sequences
- Detect nucleotide substitutions
- Display mutation position
- Show original and mutated nucleotide

## Example

Input

```
Normal DNA:
ATGCGTACGA

Mutated DNA:
ATGAGTTCGA
```

Output

```
Total Mutations: 2

Position 4 : C → A
Position 7 : A → T
```
